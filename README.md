# Ham's Ball Battles Bet Tweaks

Download the latest release [here](https://github.com/BizzarBlitz/HB3T/releases/latest)

## Features

- Provides visualizaton for bet pools and multipliers
- Shows you future multiplier and profit
- Notifies you whenever the daily wheel resets

## Manual Build Instructions

1. Install [WXT](https://wxt.dev)
2. Run `npm run build` or `wxt build` in the terminal
    - If you're using Firefox, use `npm run build:firefox` or `wxt build -b firefox` instead
3. Load the built file as an unpacked extension (you may need to enable developer mode in your browser settings to do this)
