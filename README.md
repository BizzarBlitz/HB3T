# Ham's Ball Battles Bet Tweaks

Download the latest release [here](https://github.com/BizzarBlitz/HB3T/releases/latest)

- Chrome/Chromium/Edge: Download `hb3t-1.X.X-chrome.zip`
- Firefox: Download `hb3t-1.X.X-firefox.zip`

## Features

- Provides visualizaton for bet pools and multipliers
- Shows you future multiplier and profit
- Notifies you whenever the daily wheel resets

## Manual Build Instructions

1. Install [WXT](https://wxt.dev)
2. Run `npm run zip` or `wxt zip` in the terminal
    - If you're using Firefox, use `npm run zip:firefox` or `wxt zip -b firefox` instead
3. Load the zip file as an unpacked extension (you may need to enable developer mode in your browser settings to do this)
